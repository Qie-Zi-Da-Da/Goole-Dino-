系统概述
本次课程设计的项目是一个基于 小恐龙游戏 的嵌入式系统，集成了 oled，JQ8900
语音模块，蜂鸣器等多种模块实现丰富的游戏功能。系统采用以 Mega2560 开发板为核心
的 AVR 单片机实验实践平台进行开发，使用 ICCAVR 作为软件开发环境。游戏通过 OLED
显示屏 实时呈现小恐龙跳跃躲避障碍的动画，并通过数码管记录和显示玩家的最高分数。
系统还集成了语音模块和蜂鸣器模块，以增强游戏体验。
在游戏过程中模块的使用方面，OLED 模块 用于显示游戏画面，数码管模块 显示最
高分数，蜂鸣器模块 负责在小恐龙碰到障碍时或跳跃时发出警告音效，语音模块 用于播
报游戏开始时小组课程作品的名称，ADC 模块用于检测外部传感器（如游戏速度调节等
等），实现更多互动功能。
该系统通过模块的合理组合，使得游戏更加生动有趣。数码管实时更新显示最高分，
蜂鸣器与语音模块结合带来了更加直观的反馈，整体系统具有较强的互动性和娱乐性，具
有较大的扩展和应用前景。
2. 硬件设计
2.1. 硬件总体设计
通过 Mega2560 作为整个系统的核心控制器，负责协调各个模块的工作，包括游戏逻
辑处理、分数记录、输入输出处理等。JQ8900 模块根据游戏的不同状态播放相应的语音
提示或项目背景音效。通过 IO 口控制有源蜂鸣器的开启与关闭，提供小恐龙跳跃的声音
提醒。七段数码管通过使用共阴极或共阳极的驱动方式，并通过定时器中断来控制动态刷
新最高分数的内容。每个按键连接到 GPIO 口，按键按下时触发中断输入，从而响应玩家
的操作。游戏中可以使用 ADC 模块连接的传感器进行操作调整，提升游戏的互动性。通过
整合这些硬件模块，构建一个可以响应用户输入并通过显示屏、语音和蜂鸣器进行反馈的
完整小恐龙游戏系统。
