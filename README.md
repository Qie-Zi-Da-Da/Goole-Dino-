# 基于 Mega2560 的小恐龙游戏嵌入式系统

## 📌 一. 系统概述

本次课程设计的项目是一个基于 **小恐龙游戏** 的嵌入式系统，集成了 **OLED 显示屏**、**JQ8900 语音模块**、**蜂鸣器** 等多种模块，实现了丰富的游戏交互功能。

系统采用以 **Mega2560 开发板** 为核心的 AVR 单片机实验实践平台进行开发，使用 **ICCAVR** 作为软件开发环境。游戏通过 **OLED 显示屏** 实时呈现小恐龙跳跃躲避障碍的动画，并通过 **数码管** 记录和显示玩家的最高分数。系统还集成了语音模块和蜂鸣器模块，以增强游戏体验。

### 模块功能简述

- **OLED 模块**：显示游戏画面
- **数码管模块**：显示当前最高分数
- **蜂鸣器模块**：小恐龙跳跃或碰撞时发出提示音效
- **语音模块**：播报游戏开始时的小组课程作品名称
- **ADC 模块**：用于检测外部传感器（如调节游戏速度等），实现更多互动功能

该系统通过模块的合理组合，使得游戏更加生动有趣。数码管实时更新显示最高分，蜂鸣器与语音模块结合带来了更加直观的反馈，整体系统具有较强的互动性和娱乐性，具有较大的扩展和应用前景。

## 🧱 二. 硬件设计

### 2.1 硬件总体设计

本系统以 **Mega2560 单片机** 作为整个系统的核心控制器，负责协调各个模块的工作，包括：

- 游戏逻辑处理
- 分数记录与更新
- 输入输出控制
- 中断响应与定时刷新

#### 各模块硬件连接与功能描述

| 模块 | 功能描述 | 控制方式 |
|------|----------|----------|
| **JQ8900 语音模块** | 根据游戏状态播放语音提示或项目背景音效 | 串口 / IO 控制 |
| **有源蜂鸣器** | 提供小恐龙跳跃或碰撞时的声音提醒 | IO 口高低电平控制 |
| **七段数码管** | 动态显示当前最高分数 | 共阴极/共阳极驱动，定时器中断动态刷新 |
| **按键模块** | 响应玩家操作（跳跃/开始/暂停） | GPIO 输入，外部中断触发 |
| **ADC 模块** | 连接外部传感器（如电位器），用于游戏速度调节等 | ADC 通道采样输入 |
| **OLED 模块** | 实时渲染游戏画面 | I2C / SPI 接口通信 |

通过整合以上硬件模块，系统构建了一个能够**响应用户输入**，并通过**显示屏、语音和蜂鸣器进行多维度反馈**的完整小恐龙游戏系统。
